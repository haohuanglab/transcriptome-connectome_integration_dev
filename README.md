# transcriptome-connectome_integration_dev
This repository provides core code and demo data for the manuscript "Transcriptomic underpinnings of developmental human brain connectome".

## Overview
The study integrates the dynamic trajectories of transcriptome and connectome across development to identify pivotal developmental periods for brain network formation and maturation, elucidating the underlying molecular mechanisms, and understanding how perturbation to genetic programs contributes to the dysconnectivity characteristic of major neurodevelopmental disorders. The code provided here implements the main analytical workflows, including source code and demo data for developmental trajectory modeling of connectome metrics, partial least squares (PLS) regression linking transcriptomic and connectomic patterns, bootstrap-based gene ranking, cell-type enrichment analysis, Gene Ontology and disorder-related enrichment analyses, and related downstream statistical analyses and visualizations. All data necessary to reproduce our results will be made available upon publication.

## Software Requirements
Custom code was tested on a 64-bit Windows 11 PC. No non-standard hardware is required. Data analysis was performed using: MATLAB R2020a or later, with the Statistics and Machine Learning Toolbox (plsregress), and the Parallel Computing Toolbox is recommended for the bootstrap steps; R ≥ 4.0, with the packages nlme, mgcv, tidyverse, dplyr, reshape2, stringr, readxl, openxlsx, knitr, readr, ggplot2, gridExtra, cowplot, ggrepel, directlabels, sigmoid, latex2exp, and EWCE (v1.10.2, via Bioconductor); Python ≥ 3.9, with the packages pandas, numpy, scipy, statsmodels, gprofiler-official (v1.2.2), matplotlib, seaborn, tqdm, adjustText, palettable, Pillow, plotly, kaleido, ruptures.
Other software used include: diffusion MRI preprocessing and tensor fitting for Cohorts 1 and 2 used DTIStudio (https://www.mristudio.org/), deterministic whole-brain tractography was performed using Diffusion Toolkit (v0.6.4.1, https://trackvis.org/dtk/), cortical parcellation used FreeSurfer (v6.0, https://surfer.nmr.mgh.harvard.edu/), registration of cortical parcels used SPM8 (https://www.fil.ion.ucl.ac.uk/spm/), and network metrics extraction used GRETNA (v2.0, https://www.nitrc.org/projects/gretna).

## Installation Guide
All the scripts (*.m files in MATLAB, *.R files in R, *.py files in Python) can be executed by adding the appropriate environment paths according to the corresponding language: use addpath for MATLAB, pip install for Python, and install.packages() / BiocManager::install() for R. These procedures are not time-consuming and typical installation time on a normal desktop computer is under an hour. For network metric extraction, download GRETNA and add it to your MATLAB path addpath(genpath('path/to/GRETNA')).

## Demo
The main analyses were carried out step-by-step using the source code as follows with demo data provided in the data directory.
1. Connectome network metric extraction: regional and whole-brain connectome metrics (nodal efficiency, local efficiency, shortest-path length, etc.) are computed from dMRI-derived connectivity matrices using the GRETNA toolbox, then compiled into csv files. 
2. Connectome developmental trajectory fitting: aic_eval_cohort_adjusted.R (AIC/BIC model selection and cohort-adjusted trajectory fitting at the 11 transcriptome-matched regions) and whole_brain_connectomic_fit_cohort_adjusted.R (same models at whole-brain, 256-parcel resolution).
3. Transcriptome-connectome PLS regression: PLSregression_batch.m calls PLSregression_func.m (PLS regression with permutation-based significance testing) and PLSregression_BootstrappedWeights_func.m (bootstrapped PLS1 gene weight ranking). PLS processing required functions: func_corr_metric_PLSscores.m, func_diff_rank_in_list.m, func_ReadGeneid_SavesTxt.m, func_remove_ENSG_geneIndex.m, mat2table.m, and mattable2csv.m.
4. Cell-type enrichment analysis: EWCE_demo.R; Gene Ontology enrichment analysis: go.py.
5. Disease-related cell-type and Gene Ontology enrichment analysis: disgenet_enrich.r, disgenent_traj.R, similarity_bioprocess.py, similarity_celltypes.py (DisGeNET gene-sets), receptors.R (neurotransmitter receptor gene rank extraction), magma.R (Multi-marker Analysis of GenoMic Annotation).
